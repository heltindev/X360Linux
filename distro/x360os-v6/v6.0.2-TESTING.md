# X360OS v6.0.2 — input and desktop return repair

**User feedback:** XeLL DHCP fails, wireless gamepad does not navigate, and selecting Ubuntu desktop leaves no convenient way to return to X360OS.

## Root cause proved by inspecting the shipped v6.0.1 kernel config

- `CONFIG_XENON_ENET=y`: the Xbox 360 wired Ethernet driver is built into the kernel.
- `CONFIG_JOYSTICK_XPAD=y`: USB Xbox 360 gamepad driver is built into the kernel; new `xpad.ko` is NOT required or ABI-compatible with this old kernel.
- `CONFIG_INPUT_JOYDEV=m` and `CONFIG_INPUT_EVDEV=m`: these two module files are included in the distro, but the original code tried to load them from a normal user session without root permissions, so loading can fail silently.
- `# CONFIG_WIRELESS is not set` and `# CONFIG_WLAN is not set`: the verified 2.6.36.2-xenon kernel cannot use built-in Xbox 360 Slim USB Marvell 88W8786U wireless, VID:PID 045e:0765, simply by copying firmware or installing NetworkManager. A suitable kernel build, USB chipset driver and firmware need to be developed and verified, or use wired Ethernet.
- XeLL has its own DHCP stack. Failed DHCP in XeLL **before the Linux boots** is separate from DHCP inside Ubuntu. A USB driver or Ubuntu change does not fix this pre-Linux error.

## What changes in 6.0.2

- Load joydev and evdev as root during boot via /etc/modules and rc.local fallback, not relying on unprivileged session.
- Udev access rules for joystick and Xbox-labeled input events.
- Add return action on the Ubuntu desktop through a "X360OS" clickable shortcut and Applications entry; the X360OS window remains resident when switching to GNOME. Press controller Back/Guide to request the home menu if the controller is detected.
- Expand read-only hardware report (/home/ubuntu/.x360os/hardware.txt) to include kernel input config, input devices and module state. No Wi-Fi passwords recorded.
- Retain original verified Xenon kernel and USB boot path; no NAND flashing.

## Upstream reference source downloaded (NOT installed as compatible binaries)
- Free60Project/linux-kernel-xbox360 (Free60 Xenon kernel patch; 2.6.36.2 and modern branches).
- paroj/xpad (modern xpad kernel driver; it cannot be copied into 2.6.36.2 as an .ko).
- Free60Project/xell-reloaded (XeLL network stack and kboot.conf behavior).

**Status:** development candidate; code/host checks are not proof that built-in wireless gamepad input is exposed on real Xbox 360 hardware. If there is no /dev/input/js* or matching /dev/input/event*, a hardware/driver solution is still required.
