# X360OS v6.1.0 — Classic Games & Openbox (experimental)

This version keeps the verified Free60 Xenon kernel, legacy Ubuntu 10.10 PPC32 big-endian root filesystem, XeLL/Kboot automatic USB boot, and Casper persistence.

## Added

- **Openbox 3.4.11.1 (PowerPC big-endian)** plus matching obparser/obrender runtime libraries. X360OS X11 sessions use Openbox instead of Metacity when available. Classic GNOME remains a fallback. No IceWM.
- **PrBoom 2.5.0** (2009/2010-era PPC binary) plus **Freedoom 0.6.4** free IWAD `/usr/share/games/doom/freedoom.wad`. The desktop shortcut launches the game without typing commands.
- **Chocolate Doom 1.3.0** (PPC binary) included for users who separately supply an appropriate licensed Doom IWAD. Freedoom 0.6.4 packages require a Boom-compatible engine; PrBoom is used for the bundled Freedoom rather than pretending Chocolate Doom is Boom compatible.
- Legacy SDL1.2, SDL_mixer1.2, SDL_net1.2 runtime dependencies added as available; game binaries and dependency resolution are verified on PC (QEMU smoke test where feasible).
- A read-only ALSA sound report under `~/.x360os/sound-check.txt`; sound driver already compiled in original kernel as `CONFIG_SND_XENON=y`.
- Xbox controller mapper adds a best-effort DOOM game mode (D-pad or left stick moves, A=fire, B=use, X=run). Requires Linux to expose the controller.
- Main X360OS home includes DOOM/FreeDOOM entry; shortcut also available from Ubuntu desktop.
- Existing Ethernet (Xenon ENET), NetworkManager, DHCP and wpa_supplicant retained.

## Not solved

- **Internal Xbox 360 Slim Marvell Wi-Fi**: original kernel `CONFIG_WIRELESS=n`, `CONFIG_WLAN=n`. No binary driver can fix this without porting a compatible kernel driver and WLAN stack.
- **XeLL DHCP** occurs before the Linux kernel. A Linux userspace DHCP change cannot fix that pre-boot warning.
- **Internal RF wireless gamepad** may not appear as a USB `xpad` controller at all. Needs hardware test and possibly dedicated driver.
- **GPU 3D acceleration** and modern browsers are not provided. Framebuffer and CPU software rendering remain.
- **ZRAM** only if built into or supported by matching Xenon kernel modules; do not load an incompatible modern module.

No repository CI, no NAND flashes, and no console commands are required for this test ZIP. Hardware testing required before calling the release stable.

## Test on a spare USB

1. Back up verified v5/v6.0.2 USB files.
2. Copy `BOOT-DIRETO` contents to a FAT32 USB of at least 8 GB (do not merely copy the ZIP).
3. Use Eject to load XeLL and boot from USB. Check the X360OS home, DOOM entry, and controller.
4. If menu or game fails, inspect `/home/ubuntu/.x360os/home.log`, `controller.log`, `doom.log`, `hardware.txt`, `sound-check.txt`.
5. Classic GNOME desktop is still available; use the X360OS shortcut to return.

## Reproducible workstation build

Download the ten archived Ubuntu 10.10-era `powerpc` / `all` packages using `fetch-v6.1-ppc-packages.py` into a local directory; see the exact version-pinned URLs in that script. They are retrieved from `https://old-releases.ubuntu.com/ubuntu/pool/`. Build the image using `build-v6.1-ppc.sh` with three arguments: the verified v6.0.2 `filesystem.squashfs`, local package directory, and a NEW output directory. The build checks architecture, original kernel features, WAD signature, ELF loader, and host-side QEMU smoke logs, then creates a gzip SquashFS. It does not run `apt` on the Xbox or mutate the verified kernel.

**Version details:** Openbox 3.4.11.1, PrBoom 2.5.0, Chocolate Doom 1.3.0, Freedoom 0.6.4. These are historical releases matching the old Ubuntu runtime, not current secure packages. Installed programs are overlaid from .deb contents without registering them in the legacy dpkg status database. For development and actual package upgrades, reconcile dependency metadata before running legacy APT.

**Host QEMU limitations:** PrBoom runs its initialization but cannot create an Xbox/Xenos framebuffer window on the Windows/WSL host display. It reports `No available video device`. This is expected in the headless smoke check but NOT evidence of real Xbox video or gamepad functionality.
