# Contributing to X360Linux

X360Linux is open source. The most valuable contribution is a **reproducible Xbox 360 boot test** or a focused fix that helps Linux reach a shell.

1. Start with the [project status](README.md#-project-status) and [test guide](docs/TESTING.md).
2. Test on an already modded Xbox 360; never write experimental files to NAND.
3. Share the Xbox 360 board revision, build commit, boot method and any Linux logs (remove private identifiers).
4. Send focused code changes with clear test steps. Running GitHub Actions is not a substitute for console testing.
5. Preserve license notices and original authorship for third-party sources.

English documentation, comments, commit messages and code are preferred throughout this repository.
